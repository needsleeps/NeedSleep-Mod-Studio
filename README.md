### เริ่มเล่นใน 3 ขั้นตอน

1. **ปิดเกม** แล้วเปิด `NeedSleep-Mod-Studio-Setup.exe` — ตัวเต็มรวมโปรแกรมและแพ็ก client ไว้ในไฟล์เดียว
2. เปิดชอร์ตคัต **NeedSleep Mod Studio** บนเดสก์ท็อป โปรแกรมจะค้นหาโฟลเดอร์เกมให้ หากไม่พบให้กดเลือกโฟลเดอร์
3. เลือก **ติดตั้งแบบสมบูรณ์** แล้วกดติดตั้ง รอจนตรวจไฟล์เสร็จจึงเข้าเกม

ครั้งต่อไป **เปิดชอร์ตคัตเดิม** ได้เลย Launcher จะตรวจเวอร์ชันก่อนเปิดโปรแกรมหลัก และดาวน์โหลดอัปเดตเมื่อจำเป็น

### เลือกดาวน์โหลดแบบไหนดี?

| ไฟล์ | เหมาะกับใคร |
|---|---|
| **NeedSleep-Mod-Studio-Setup.exe** | เริ่มติดตั้งครั้งแรก ต้องการตัวเต็มพร้อมแพ็กทั้งหมด |
| **NeedSleep-Launcher.exe** | ต้องการตัวเปิดขนาดเล็ก ให้โปรแกรมดาวน์โหลดชุดเต็มเอง |
| ไฟล์ catalog / update / SHA256SUMS | ข้อมูลสำหรับระบบอัปเดต ไม่ต้องเปิดเอง |

> อัปเดตเป็น **ชุดเต็มหนึ่งแพ็ก** จึงอาจใช้เวลาโหลดตามขนาดชุดและความเร็วเน็ต ไม่ต้องเลือกโหลดไฟล์ม็อดทีละรายการ

### ภายในโปรแกรม

| หมวด | ใช้ทำอะไร |
|---|---|
| **ติดตั้งแบบสมบูรณ์** | พื้นฐาน + ม็อดการเล่น + แก้ปัญหา ไม่เลือกสองหมวดพิเศษ |
| **แก้ปัญหา** | ปิด UObject cache ซ่อนหน้าต่าง Debug ซ่อมข้อมูลที่รองรับ และถอด Basic Minimap ตามตัวเลือก |
| **พื้นฐาน / ม็อดการเล่น** | เลือกตรวจ ติดตั้ง หรือถอนเฉพาะรายการที่ต้องการ |
| **พิเศษ / พิเศษใส่ไข่** | ตัวเลือกเพิ่มเติม แยกจากชุดสมบูรณ์ |
| **ที่ติดตั้งแล้ว** | ตรวจรายการและเลือกถอนม็อดที่ไม่ต้องการ |

### ระบบอัปเดตทำงานอย่างไร?

`ชอร์ตคัต → Launcher → ตรวจเวอร์ชัน → ดาวน์โหลดและตรวจไฟล์ถ้ามีรุ่นใหม่ → เปิด Mod Studio`

- โปรแกรมอยู่ใน `%LOCALAPPDATA%\NeedSleepModStudio` ของผู้ใช้
- แยก Launcher ออกจากโปรแกรมหลัก เพื่อแทนที่ EXE หลักขณะอัปเดตได้
- ตรวจลายเซ็นประกาศและ SHA-256 ก่อนใช้ไฟล์อัปเดต
- หากเน็ตขาด โปรแกรมเก็บไฟล์บางส่วนไว้เพื่อโหลดต่อเมื่อลองใหม่
- มีปุ่ม **ตรวจเวอร์ชัน / อัปเดต** ในหน้าแรก
- ปิดเกมก่อนเปลี่ยนไฟล์ม็อด รุ่นที่กำหนดเป็นแพตช์บังคับต้องอัปเดตก่อนทำรายการ
- การติดตั้งแบบสมบูรณ์จำโปรไฟล์ไว้เพื่อรับม็อดการเล่นที่เพิ่มในชุด โดยไม่เลือกม็อดพิเศษให้อัตโนมัติ
