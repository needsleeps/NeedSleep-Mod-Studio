### เริ่มใช้งาน

1. **ผู้เล่นใหม่:** เปิด `NeedSleep-Launcher.exe` ไฟล์เดียว โปรแกรมจะดาวน์โหลดตัวโปรแกรมและข้อมูลตั้งต้นให้เอง (ข้อมูลม็อดครั้งแรกประมาณ 1 GB)
2. **ผู้ใช้รุ่นเดิม:** ปิด Mod Studio แล้วเปิด `NeedSleep-Launcher.exe` รุ่นใหม่หนึ่งครั้ง เพื่อซ่อมชอร์ตคัตและเพิ่มระบบแพตช์ต่อเนื่อง
3. ใช้ชอร์ตคัต **NeedSleep Mod Studio** บนเดสก์ท็อป → รออัปเดต → เลือก **ติดตั้งแบบสมบูรณ์**

**ปิดเกมก่อนเปลี่ยนไฟล์ม็อด** หากไม่พบเกมอัตโนมัติ ให้เลือกโฟลเดอร์ Palworld ที่มีโฟลเดอร์ Pal อยู่ภายใน

### เปิดชอร์ตคัต แล้วปล่อยให้ Launcher จัดการ

`ตรวจรุ่น → โหลดแพตช์ที่ต้องใช้ → ตรวจไฟล์ → ลงทีละขั้นจนล่าสุด → เปิดโปรแกรมหลักครั้งเดียว`

- แสดงเปอร์เซ็นต์ ขนาดดาวน์โหลด ความเร็วเน็ต และเวลาคงเหลือโดยประมาณ
- แยก **รุ่นโปรแกรม** กับ **รุ่นข้อมูลม็อด** — แก้ม็อดอย่างเดียวไม่ต้องโหลด EXE เต็มใหม่
- โปรแกรมเก่าไล่แพตช์ต่อกัน ไม่เปิดหน้าหลักคั่นระหว่างแต่ละรุ่น
- ขั้นไหนขาดหรือผิดรุ่นจะหยุดแจ้ง ไม่ข้ามไปเอง
- ตรวจลายเซ็นประกาศและ SHA-256 ก่อนใช้แพตช์ โหลดต่อได้เมื่อลองใหม่
- ติดตั้งสำเร็จมีปุ่มเปลี่ยนสี พร้อมนับถอยหลัง **10 วินาที** กันกดซ้ำ

### เลือกสิ่งที่จะติดตั้ง

| หมวด | การใช้งาน |
|---|---|
| **ติดตั้งแบบสมบูรณ์** | พื้นฐาน + ม็อดการเล่น + แก้ปัญหา |
| **แก้ปัญหา** | เลือกซ่อมเฉพาะงาน เช่น UObject cache / Debug / Basic Minimap |
| **พื้นฐาน / ม็อดการเล่น** | เลือกตรวจ ติดตั้ง หรือถอนเป็นรายม็อด |
| **พิเศษ / พิเศษใส่ไข่** | ตัวเลือกเพิ่มเติม ไม่ติดตั้งในชุดสมบูรณ์ให้อัตโนมัติ |
| **ที่ติดตั้งแล้ว** | ตรวจสถานะและเลือกถอนสิ่งที่ไม่ต้องการ |

### ไฟล์ใน Release

| ไฟล์ | ต้องเปิดเองไหม? |
|---|---|
| **NeedSleep-Mod-Studio-Setup.exe** | เปิดเมื่อติดตั้งครั้งแรกหรือต้องการซ่อมฐาน |
| **NeedSleep-Launcher.exe** | เปิดครั้งแรกเพื่อสร้าง/ซ่อมชอร์ตคัต |
| Main / Bridge / Patch / Data / Catalog / update / SHA256SUMS | Launcher ใช้อัตโนมัติ ไม่ต้องเลือกดาวน์โหลดเอง |

ข้อมูลม็อดอยู่ใน `data` ตัวโปรแกรมหลักอยู่ใน `app` และไฟล์ดาวน์โหลดอยู่ใน `cache` ภายใต้โฟลเดอร์ NeedSleepModStudio ของผู้ใช้ แพตช์ข้อมูลจะเปลี่ยนเฉพาะข้อมูลที่ต้องใช้ โดยเก็บสถานะหลังแต่ละขั้นสำเร็จ
